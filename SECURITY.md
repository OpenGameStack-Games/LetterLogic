# Security Policy

## Supported Versions

LetterLogic receives security updates and bug fixes on the current release branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of LetterLogic and our players seriously. If you discover a security vulnerability or sensitive defect, please report it responsibly:

### How to Report
- **Email:** Send details of the vulnerability directly to **contact@opengamestack.org**.
- **GitHub Security Advisory:** Alternatively, you can use the **Report a vulnerability** button under the [Security tab](https://github.com/OpenGameStack-Games/LetterLogic/security/advisories) on GitHub.

Please **do not** open a public issue for security vulnerabilities.

### What to Include
To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce or a proof of concept.
- The target environment (e.g., Godot version, OS, Android version).

### Response Timeline
- **Acknowledgement:** We will acknowledge receipt of your report within 48 hours.
- **Triage & Remediation:** We will assess the report and provide an estimated timeline for a patch.
- **Disclosure:** Once a fix is released, we will credit reporters who followed responsible disclosure practices (unless you prefer to remain anonymous).
